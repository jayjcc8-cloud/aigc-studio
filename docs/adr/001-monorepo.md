# ADR 001：采用 Monorepo 组织 AI 短剧工作流

- 状态：已接受
- 日期：2026-07-24

## 背景

AI 短剧生产涉及剧本、分镜、视频生成、音频、合成、审核、发布等多个环节，
各环节需要共享同一套领域模型（Project / Shot / Asset）和配置规范。
如果拆成多个仓库，跨环节改动会产生版本对齐成本，容易退化为"脚本缝合怪"。

## 决策

采用单仓库（Monorepo），按能力域拆分为多个 Python 包：

- `aigc-core`：领域模型、配置、Provider 接口，**不依赖任何具体供应商 SDK**。
- 其余 `aigc-*` 包按环节划分，只依赖 `aigc-core` 和必要的第三方库。

包之间通过 `src` 布局 + setuptools `packages.find` 一次性安装，共用
`pyproject.toml` 中的 lint/类型检查/测试配置，保证全仓库标准统一。

## 后果

- 优点：一次 PR 完成跨环节改动；CI 统一；重构成本低。
- 代价：仓库体积随素材增长——通过 `projects/` 目录 `.gitignore` + 对象存储规避。
- 约束：新增能力必须建独立包或归入现有包的明确模块，禁止在根目录堆脚本。
