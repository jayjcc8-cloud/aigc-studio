# ADR 004：商业定位——IP 试制与验证平台

- 状态：已接受
- 日期：2026-07-24
- 关联：[商业策略文档](../strategy/business-model.md)、ADR 003（生产策略）

## 背景

低质同质化供给已严重饱和（抖音集团端 2026-06 月增约 2.37 万部 AI 短剧，
爆款率估计约 0.16%）。单纯"批量生产等爆款"或"低价代制作"都不构成
可持续业务。团队的核心优势在自动化、成本控制与数据化，而非内容抽卡。

## 决策

1. **定位**：B2B 现金流 + 数据驱动自有 IP 孵化 + 自动化生产系统，
   对外形态是"IP 试制与验证平台"。不以价格为卖点。
2. **交付物三档**成为一等产品概念：概念样片（60–90s）、试播集（3–5min）、
   整剧；只有前一档验证通过才进入下一档。
3. **概念测试漏斗与止损规则产品化**：漏斗（10 概念 → 3 开场/个 → 2 →
   试播 → 1 → 小季 → 整剧）和四条止损规则进入系统，而非停留在文档。
4. **指标采集前置**：前 3/5 秒留存、完播率、下一集点击、关注转化、
   催更意图、自然增长，作为项目数据的必备字段（Phase 2 数据回流的基础）。
5. **项目级盈亏核算**：在 ADR 003"每可用秒成本"之上，按项目聚合
   直接成本与收入（制作费/分账），支撑 B2B 报价与自营投资决策。
6. **题材与 IP 原则**进入选题环节约束：AI 有视觉优势的题材、
   中腰部已验证 IP、"成熟结构 + 稀缺专业设定"。
7. **多语言改编**作为管线能力预留，但只服务已验证项目（出海是放大器）。

## 对工程路线图的影响

- Phase 1 不变（先跑通生产技术链），但首个完整交付物以"概念样片"
  规格验收（60–90s，而非此前设想的 30s）。
- Phase 2 增加：交付物模板（样片/试播/整剧规格）、概念测试漏斗与
  指标采集、项目级盈亏报表。
- Phase 3 增加：多语言改编管线、B2B 客户项目管理。

## 团队含义

- 必须补齐内容负责人（短剧节奏/剧本）与商务负责人（平台/IP/发行）
  两个合伙角色；技术团队不扩"模型操作员"岗位。

## 已评估但未采纳

- 自建海外短剧 App + 投流（风险极高，初期不做）。
- 高价买断头部 IP（改走中腰部 IP 低额授权 + 分成）。
- 低价代制作作为主业务（仅作现金流补充，产能占比设限）。
