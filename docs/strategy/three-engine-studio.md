# 策略：三引擎个人 AIGC 工作室

> 来源：2026-07-24 内部研究报告（用户输入）。与 [商业策略](business-model.md)
> 的关系见 [ADR 005](../adr/005-three-engine-studio.md)。

**一句话**：用 AIGC 卖结果，用自动化积累软件资产，用自有 IP 保留非线性收益。

**前 6 个月精力分配**：70% 垂直服务（有明确付款人）/ 20% 内部自动化 / 10% 自有 IP 实验。

## 定位

> 面向 AI 产品、App 和独立游戏的**多模态内容发布与本地化工作室**。

不是"AI 漫剧工厂"，不是泛化"AI 万能工具"。漫剧生产线是核心资产之一，
但现金流来自更广的内容交付。选择 AI 产品/独立游戏赛道的原因：
客户要的是产品表达和转化而非单纯画面；每次项目只需几十秒到几分钟视频，
不承担长篇一致性成本；服务中积累的角色/叙事/视觉能力反向支持自有 IP。

## 一个输入，多种输出

```text
产品文档 / 游戏 Demo / IP 设定 → 统一知识库与品牌规范
├─ 产品介绍文案          ├─ 落地页              ├─ 应用商店素材
├─ 15/30/60 秒宣传视频   ├─ 角色/产品视觉图     ├─ 多语言配音与字幕
├─ 社交媒体内容包        └─ 教程/演示视频/互动样片
```

## 三台引擎

### 1. 现金流引擎：产品化服务（套餐制，不接无限定制）

| 套餐 | 内容 | 试价 |
|---|---|---:|
| A. 产品发布基础包 | 卖点整理 + 落地页文案 + 3-5 视觉图 + 30s 视频 + 中英双语 + 首发社交内容 | ¥2,000–5,000 |
| B. 游戏叙事宣传包 | 世界观/角色整理 + 商店页 + 角色图 + 30–60s 预告 + 5-10 条社交内容 + 英/日本地化 | ¥5,000–15,000 |
| C. 持续内容合作 | 固定服务费 + 模型调用额度 + 超额使用费（不做"无限生成"纯订阅） | 按月 |

### 2. 产品引擎：内部 AIGC 操作系统（先自用，不对外 SaaS）

七个模块：**项目知识库**（产品资料/IP 设定/角色档案/品牌语气/禁忌）、
**任务模板**、**模型适配器**（已有）、**资产管理**（已有）、
**人工审批**（已有）、**成本账本**（已有）、**导出系统**（多比例/多语言）。

功能开发三条件（同时满足才做）：重复出现 ≥5 次 + 月省 ≥5 小时 + 3 个月收回开发成本。

### 3. 资产引擎：自有 IP（长期期权，不动用生活本金）

方向：AI 社会、近未来科技、自动化与人、数字身份、虚拟人格、游戏世界经济。
首发形态不是长篇动画，而是**互动网页故事 / 视觉小说 / 短篇叙事游戏 /
角色化 AI 体验**——同一套工作流既服务客户也服务自有 IP。
IP 预算 ≤ 月度可支配利润的 10–20%，出现稳定回访和付费信号后再加注。

## 90 天执行方案

- **第 1–30 天**：窄切口"为 AI 产品和独立游戏做多语言发布内容包"；
  3 个真实产品样例 + 作品网站；联系 30–50 个目标团队；3 个试单名额；
  目标 = **至少 1 个真实付费客户**。不开发平台。
- **第 31–60 天**：记录每个项目的耗时/返工/模型成功率/真实成本/付费意愿；
  只为满足三条件的环节写自动化。
- **第 61–90 天**：3–5 个付费客户、2 个标准套餐、1 个持续合作、
  内部后台第一版、每项目留成本利润记录。90 天后按数据分流
  （需求相似→轻量 SaaS；游戏客户多→深耕游戏本地化；无人付费→换垂直领域）。

## 止损规则（10 条）

1. 无付费客户不开发完整 SaaS；2. 单自动化模块开发 ≤ 2 周；
3. 不买 GPU、不自建模型集群；4. 不依赖单一平台分账；
5. 不接无限修改/无限生成；6. 不把模型名称当卖点；
7. 新方向 30 天内必须获得真实付款验证；8. 自有 IP 不影响现金流；
9. 所有资产保存模型/prompt/编辑过程/授权信息；10. 不做低质内容矩阵。

## 合规

《人工智能生成合成内容标识办法》（2025-09-01 施行）覆盖文本/图片/音频/
视频/虚拟场景，区分显式与隐式标识。YouTube 已将批量重复内容排除在变现外，
TikTok 强化 AIGC 标识。合规从工作流第一天内建，不上线前临时补。

## 资产持久性排序（投资优先级）

| 资产 | 持久性 |
|---|---:|
| 单模型提示词技巧 / 单平台流量玩法 | 很低 |
| API 编排与模型路由 | 中 |
| 垂直行业工作流 | 较高 |
| 客户关系与业务数据 | 高 |
| 品牌、社群、自有 IP | 很高 |

## AI 辅助开发纪律

每个模块：人写需求与数据结构 → AI 生成第一版 → 人阅读解释代码 →
人编写/检查测试 → AI Review → 人负责合并与排错。
人必须亲自掌握：数据模型、API、异步任务、错误处理、成本计算、
权限安全、日志测试。AI 可写大量代码，但不能独自决定架构。
