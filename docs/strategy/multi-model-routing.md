# 策略：角色参考图驱动的分镜级多模型路由

> 来源：2026-07-24 内部研究报告（用户输入），已采纳为生产策略。
> 决策记录见 [ADR 003](../adr/003-shot-level-multi-model-routing.md)。

**核心原则**：不要把整部短剧交给一个"最强模型"。按镜头路由到不同档位模型，
优化的目标是**每个可用镜头的成本**，而不是厂商标注的每秒价格。

## 整体流水线

```text
选题 → 剧集圣经/角色圣经/单集剧本 → 结构化分镜 JSON
→ 角色定妆图/场景图资产库
→ 静帧分镜 + 临时配音 → Animatic 预演
→ 一审（故事/节奏/角色）          ← 回报率最高的审核节点
→ 镜头路由器（按档位分发）
→ 自动质检 → 自动重试或升级模型
→ 粗剪 → 二审（只选可用镜头）
→ 口型修复/字幕/配乐/响度标准化/超分
→ FFmpeg 自动成片 + AIGC 标识与元数据
→ 终审与发布
```

**最关键设计**：先生成静态分镜 + 配音预演确认剧情节奏，再花钱生成视频。

## 模型路由表

| 层级 | 模型 | 适用镜头 | 公开成本参考 |
|---|---|---|---|
| 廉价草稿 | Wan 2.6 Flash | 空镜、道具、背影、简单运镜、无口型 | 720P 无声 ¥0.15/s，有声 ¥0.30/s |
| 廉价人物运动 | MiniMax Hailuo 2.3 Fast | 单角色走动/转身/短反应 | 768P I2V 6s ¥1.35 |
| 主力质量 | HappyHorse 1.1 I2V/R2V | 单/双角色表演、参考图一致性 | 720P 原价 ¥0.90/s（限时六折 ¥0.54，预算按原价） |
| 对白与连续性 | Wan 2.7 I2V/R2V | 自定义对白音频、首尾帧衔接、视频延续 | 720P ¥0.60/s，1080P ¥1/s |
| 复杂救场 | Kling 3 / Kling 3 Omni | 多参考图、复杂动作、参考视频 | 720P 无声 ¥0.60/s，有声 ¥0.90/s |
| Hero 镜头 | Seedance 2.0 / Gemini Omni Flash | 开场、高潮、营销镜头（5–10%） | Seedance 720P ~$0.36/s，Gemini ~$0.10/s |
| 口型修复 | PixVerse Lipsync | 满意画面仅修口型（优于重生成） | ¥0.12/s |
| 成片超分 | PixVerse Upscale / 本地超分 | 只处理已过审镜头 | ¥0.15/s |

**默认流量比例**：廉价层 50% / 主力 30% / 对白连续性 15% / 复杂+Hero 5%。

## 路由规则（规则驱动，不让 LLM 自由发挥）

```text
无人物、无对白、动作简单        → Wan 2.6 Flash
单人物、已有优质首帧、动作简单   → Hailuo 2.3 Fast
角色脸部重要、需稳定参考图       → HappyHorse 1.1 R2V
有自定义对白音频 / 首尾帧衔接    → Wan 2.7
多参考图、参考视频、复杂运镜     → Kling 3 Omni
开场、高潮、关键营销镜头         → Gemini Omni Flash / Seedance 2.0
```

同一模型最多自动重试 1–2 次；超限后依次：简化动作 → 缩短镜头 → 拆镜头 →
改反应/插入镜头 → 最后才升级更贵模型。**无限重试是最大预算黑洞。**

## 生产要点

1. **结构化剧本**：LLM 输出含 `shot_id / model_tier / max_attempts / budget_cny /
   continuity_from` 的严格 JSON；维护剧集圣经、角色圣经、场景圣经、连续性状态。
2. **角色资产库**：季初高投入锁定（正面/侧面/全身/6-8 表情/每套服装/固定
   voice_id），整季复用，不每集重新生成。
3. **Animatic 先行**：静帧 + 轻微推拉 + 临时 TTS + 字幕，先验证钩子、节奏、
   时长，砍掉不值得生成视频的镜头。
4. **配音优先于对白画面**：先定稿配音 → 得精确时长 → 分镜匹配音频 → 音频喂给
   Wan 2.7 或成片后口型同步。对白镜头多用单人特写/正反打。
5. **自动质检**：人脸数量、主角脸部相似度、多余肢体、黑帧冻帧、时长匹配、
   ASR 对稿、口型、水印、安全区、响度。
6. **成本纪律**：候选全部先 720P，过审后再超分；15–25% 成片时长用静帧/2.5D/
   空镜；口型问题用 ¥0.12/s 修复而非重做视频；预算按可用秒核算。

## 成本模型（90s / 20 镜头 / 720P 候选）

| 档位 | 平均候选数 | 单集直接模型成本 |
|---|---:|---:|
| 经济型 | ~1.5 | ¥35–55 |
| **均衡型（推荐）** | ~2 | **¥85–125** |
| 高质量型 | ~2.5–3.5 | ¥180–350 |
| 广告级 | 多轮人工 | ¥350+ |

首批试播集按 **¥120–250/90s** 预留（候选数未稳定前更高）。

**后台核心指标**：首轮通过率、每镜头平均候选数、每可用秒成本、
每分钟成片人工审核时长。

## 合规（必须进入导出流程）

依据《人工智能生成合成内容标识办法》（2025-09-01 施行）：

```text
版权/授权检查 → 真人肖像声音授权检查 → 敏感内容检查
→ "AI生成" 显式标识 → 写入 AIGC 元数据（生成属性/服务方/内容编号）
→ 平台发布主动勾选 AI 声明
```

禁止未经许可克隆真人声音形象；音乐/字体/素材保留来源授权记录。

## 落地顺序

1. 建 **30 个代表镜头基准集**（对白特写/正反打/走坐/强情绪/夜景/手部道具/
   首尾帧/多角色/动作高潮/空镜）；
2. 各候选模型跑同一批，盲评：角色一致性 30% / 表演动作 25% / 口型声音 15% /
   画质 15% / 首轮通过率 10% / 单位可用秒成本 5%；
3. 胜出组合做一集 90s 试播集，稳定后扩整季。
