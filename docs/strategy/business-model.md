# 策略：B2B 现金流 + 数据驱动 IP 孵化 + 自动化生产系统

> 来源：2026-07-24 内部研究报告（用户输入），已采纳为商业策略。
> 决策记录见 [ADR 004](../adr/004-business-positioning.md)。

**核心判断**：AI 漫剧不是需求饱和，而是低质同质化供给严重饱和
（2026-06 仅抖音集团端月增约 2.37 万部，爆款率估计约 0.16%）。
"批量生产、等待爆款"接近赌博。正确定位是 **IP 试制与验证平台**：

```text
B2B 现金流业务 + 数据驱动的自有 IP 孵化 + 自动化生产系统
```

## 商业模式优先级

| 模式 | 风险 | 利润潜力 | 定位 |
|---|---:|---:|---|
| 自费整剧靠平台分账 | 极高 | 高但概率低 | 不做起步模式 |
| 低价代制作（400–600 元/分钟） | 中 | 递减 | 只做现金流，不打价格战 |
| IP 方联合出品 | 中 | 较高 | **重点发展** |
| 平台定制/保底/采购 | 较低 | 中 | **优先争取** |
| 工作流/工具/技术服务 | 较低 | 可持续 | 验证后发展 |
| 自建海外 App 投流 | 极高 | 理论高 | 初期不做 |

**卖点不是便宜**，而是：更快完成 IP 验证、更稳定的角色一致性、
更透明的成本、更高的成片通过率。

## B2B 产品三档

1. **IP 概念样片**（60–90s 预告）：角色定妆 + 世界观 + 关键冲突，
   帮客户判断 IP 是否适合漫剧化。
2. **试播集**（3–5 分钟）：对白、连续剧情、配音、字幕、平台测试版本。
3. **整剧生产**：仅在样片验证通过且有制作费/保底后启动。

合同要点：制作费覆盖全部直接成本；按"验收通过的成片分钟"计价；
修改次数封顶；争取"基础制作费 + 分账"；纯分成项目只占少量产能。

## 自有 IP：风险投资式生产漏斗

```text
10 个故事概念 → 各做 3 个 30–60s 开场 → 测数据
→ 保留 2 个 → 3–5 分钟试播集 → 保留 1 个
→ 10–20 分钟小季 → 平台/发行数据验证 → 整剧
```

**止损规则**：
1. 概念测试 ≤ 整剧成本 1–2%；2. 试播集 ≤ 整剧预算 10%；
3. 两轮修改仍低于账号基准数据即终止；4. 单项目 ≤ 月预算 20%。

**关键指标**（不看播放量绝对值）：前 3/5 秒留存、首集完播率、
下一集点击率、关注收藏转化、评论区催更意图、单个追剧用户成本、
不投流时的自然增长。

## 题材与 IP 策略

- 不买高价头部 IP；找**中腰部已验证 IP**（有阅读数据未影视化），
  低额授权费 + 作者参与改编 + 上线分成。
- 题材选 AI 相对真人有明显优势的方向：高成本奇幻、非人主角、
  中式志怪、轻科幻末世、历史架空、可长期复用世界资产的系列。
- 差异化公式：**成熟叙事结构 + 稀缺专业设定**（如修仙+工业文明、
  志怪+现代职业、近未来 AI 社会+商业斗争）。
- 普通都市恋爱/家庭伦理等真人更自然的题材不做主攻。

## 收入结构（早期健康配比）

```text
60% 确定性制作与服务收入（B2B 样片/定制/技术服务）
30% 自有或联合 IP 分账
10% 海外、工具与新业务实验
```

## 出海原则

出海是已验证项目的放大器，不是失败项目的出口：只做已验证故事的
多语言版、平台版权合作、自然流测试、定制订单；不自建 App、不投流。

## 团队能力缺口

技术侧（自动化/路由/成本/质检/多语言/盈亏分析）是我们的优势；
必须补齐两个合伙能力：**懂短剧节奏的内容负责人**、
**懂平台/IP/发行的商务负责人**。模型操作员不是关键岗位。

## 90 天验证方案

- **第 1 月**：3 个方向 × 3 个 30–60s 开场 = 9 个样片，记录单镜头
  成本、每分钟人工、角色一致性通过率、留存互动数据。
- **第 2 月**：2–3 个中腰部作者/工作室付费样片，完成 ≥1 个真实
  付费 B2B 项目。
- **第 3 月**：最优题材做 10–15 分钟试播版，同时向平台/MCN/发行方
  提交合作；数据 + 合作信号双达标才启动整剧。
